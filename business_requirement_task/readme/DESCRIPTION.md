This module links business requirements to project tasks, so each requirement
can track the tasks that implement it and the hours allocated to them.

It fills the gap left by the `business_requirement_*_project` modules that were
not migrated beyond earlier versions: instead of generating projects and tasks
from requirement resource lines, it provides a simple, direct link between a
business requirement and the project tasks that execute it, with task counters
and an allocated hours rollup on the requirement.
