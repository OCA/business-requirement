1. Open a business requirement and set its **Project**.
2. Use the **Create Task** button in the header to create a task already linked
   to the requirement: the task form opens with the requirement, project,
   customer and name pre-filled.
3. Alternatively, open any project task and set its **Business Requirement**
   field. If the task has no project yet, it inherits the project of the
   requirement; if both projects differ, a non-blocking warning is shown.
4. The **Tasks** smart button on the requirement shows the number of linked
   tasks and opens their list. The requirement also exposes the number of open
   tasks and the total allocated hours of its tasks.
5. In the tasks search view you can filter tasks that have a business
   requirement and group tasks by requirement.

A requirement with linked tasks cannot be deleted.
