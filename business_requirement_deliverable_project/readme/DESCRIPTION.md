This module creates project tasks from the deliverables of a business
requirement when it is approved, and links them to the requirement.

- Each deliverable becomes a task. Its allocated time is the deliverable
  quantity when it is measured in time units.
- Tasks can be created in an existing project, or in a new project
  created for the requirement.
- Tasks get a *Business Requirement* field, which can be searched and
  grouped by, so tasks can also be linked by hand.
- Business requirements get a *Tasks* smart button listing their tasks.
